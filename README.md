# Redragon Gaming Setup

Una Product Landing Page de una empresa ficticia inspirada en Redragon.

El proyecto presenta diferentes periféricos gaming, incluyendo un teclado mecánico, un mouse y auriculares. La página cuenta con una sección de características, un video de demostración, productos y un formulario.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Variables
- Media Queries

## Características

- Diseño responsive.
- Navegación interna.
- Formulario de correo electrónico.
- Video de demostración.
- Tarjetas de productos.
- Variables CSS para reutilizar colores y estilos.
- Diseño inspirado en periféricos gaming.

> Proyecto realizado con fines educativos. Redragon Gaming Setup es una empresa ficticia creada para este proyecto.
